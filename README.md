# Meu Treino

App pessoal (PWA) que lê a ficha de treino de uma planilha do Google, por meio de um Apps Script, e mostra um exercício por vez, com timer de descanso, registro de cargas e histórico.

- Os dados da planilha não ficam neste repositório. O endereço do Apps Script é configurado no próprio app.
- Registros, edições e histórico ficam guardados no celular (localStorage), com opção de backup.
